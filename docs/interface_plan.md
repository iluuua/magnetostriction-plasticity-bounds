# План первого интерфейса Al / Fe4Al13

Интерфейс в этом запуске не собран намеренно. Отдельная фаза Fe4Al13 прошла sanity-run, но для плоской границы нужен выбор ориентаций и оценка mismatch; автоматическая склейка произвольных slabs дала бы слабую физическую модель.

## Предлагаемый безопасный порядок

1. Выбрать 2-3 низкоиндексные плоскости Fe4Al13 из monoclinic C2/m: например (100), (010), (001).
2. Для Al проверить кандидаты fcc (100), (110), (111).
3. Для каждой пары построить 2D supercell matching и посчитать mismatch по двум периодическим направлениям.
4. Оставить только варианты с умеренной деформацией supercell; целевой первый тест - минимальный размер до 20k атомов.
5. Собрать `[Al slab] | [Fe4Al13 slab]` с нормалью к интерфейсу вдоль непериодического/релаксируемого направления, но с периодикой вдоль интерфейса.
6. Удалить атомы ближе безопасного cutoff на границе. Начальный cutoff должен быть подтверждён по ближайшим Al-Fe расстояниям; не выбирать его вслепую.
7. Сначала выполнить только minimization и короткий NVT/NPT без внешнего напряжения.
8. Только после стабильного ненагруженного интерфейса готовить сценарий 120 MPa.

## Следующий конкретный шаг

Написать отдельный скрипт `analysis/python/build_flat_interface.py`, который перебирает пары ориентаций, печатает mismatch и сохраняет только кандидата после явного выбора. До этого не создавать `data.interface` как физически значимый объект.
