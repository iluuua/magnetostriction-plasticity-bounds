## Метод и ограничения

- Al surface lattice uses fcc primitive translations inferred from the relaxed Al conventional cell.
- Fe4Al13 surface lattice uses the relaxed triclinic conventional LAMMPS cell; centered-lattice primitive reductions are not applied.
- 2D supercells are integer 2x2 combinations of the approximate surface basis vectors.
- Mismatch is reported independently for two sorted in-plane vector lengths plus the acute in-plane angle.
- Reasonable means max length mismatch <= 5%, angle delta <= 3 deg, and area mismatch <= 8%.
- These numbers do not validate an interface; they only rank candidates for the next explicit build step.
