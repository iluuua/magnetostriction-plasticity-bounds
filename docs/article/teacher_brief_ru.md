# Краткая записка для преподавателя

Дата: 2026-06-04. 1–2 страницы. По фактическому состоянию локального репозитория (включая ещё не
закоммиченную работу). Без завышений.

## Тема

Молекулярно-динамическое (MD) моделирование контакта алюминия с интерметаллидом Fe₄Al₁₃ / Al₁₃Fe₄.
Магнитное поле напрямую не моделируется; его действие заменено механическим суррогатом. Две упрощённые
геометрии: плоская граница Al(111)/Fe₄Al₁₃(100) и эллипсоидное включение Fe₄Al₁₃ в матрице Al.

## Что уже сделано

**Ветка 1 (плоская граница, 618 атомов):** релаксация Al и Fe₄Al₁₃; mismatch-выбор ориентации
Al(111)/Fe₄Al₁₃(100) (mismatch 0.943 %); сборка, минимизация, короткий и длинный ненагруженный NVT
300 K; ненагруженная диагностика; контролируемая серия нагрузок **0 / 60 / 120 / 147 / 200 MPa**;
ручной OVITO-обзор.

**Ветка 2 (эллипсоид, 24 259 атомов):** сборка и минимизация; ненагруженный NVT 300 K baseline; серия
заданных деформаций включения (eigenstrain) **ε_z = 0.0010 / 0.0025 / 0.0050 / 0.0100**.

## Какие методы

LAMMPS; потенциалы EAM Zhou (baseline Al) и MEAM Jelinek 2012 (граница/включение); NVT при 300 K, шаг
0.001 пс; напряжение на атом — `compute stress/atom NULL virial` (comparative virial proxy); проверки
устойчивости (ERROR/nan/lost atoms, Dangerous builds, межатомные расстояния 1.8 / 2.1 Å) и ручной
OVITO-обзор.

## Что показывают результаты

- Обе ветки **не разрушаются численно**: нет ERROR/nan/потери атомов, Dangerous builds = 0, нет жёстких
  overlap < 1.8 Å во всех завершённых сценариях.
- Для 147 и 200 MPa нет cross-slab Al-Fe контактов < 2.1 Å; warning-пара 232-260 — внутренняя для
  Fe₄Al₁₃, без монотонного схлопывания.
- Ручной OVITO-обзор не выявил видимого отрыва интерфейса, пустого зазора, выброса атомов или дрейфа блока.
- Серия eigenstrain прошла script-level sanity; ε_z = 0.0100 — численная stress-test точка.
- Главный результат — **воспроизводимый MD-пайплайн** обеих веток.

## Что пока НЕ доказано (честно)

- Это **не** финальная физическая валидация интерфейса/включения.
- Напряжения — сравнительный virial proxy, **не** абсолютные экспериментальные значения.
- 200 MPa — **upper-bound / failure-probe**, не подтверждённая прочность.
- Эллипсоидный eigenstrain — численный суррогат, **не** калиброванная магнитострикция.
- Нет сравнения с экспериментом/микроскопией; нет валидированного анализа дефектов/дислокаций.
- Максимум гидростатического proxy — у фиксированной опоры (вероятный артефакт граничного условия).
- OVITO-скриншоты в репозитории не сохранены (обзор был ручным).

## Следующие шаги

Калибровка амплитуды воздействия под эксперимент; альтернативные ориентации границы и размеры включения;
нагруженные прогоны эллипсоида после eigenstrain; анализ дефектов (CNA/DXA); сравнение с литературой/
микроскопией; сохранение OVITO-скриншотов; решение по хранению сырых данных (Git LFS / внешний архив).
