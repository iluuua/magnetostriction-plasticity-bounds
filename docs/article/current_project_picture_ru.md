# Текущая картина проекта (для преподавателя)

Дата: 2026-06-04. Документ описывает фактическое состояние проекта по локальным файлам
репозитория, включая ещё не закоммиченную работу. Стиль: без завышений; числа снабжены
ссылками на источник.

## Что мы моделируем

Молекулярно-динамическую (MD) модель контакта алюминиевой матрицы (Al) с железосодержащей
интерметаллидной фазой Fe₄Al₁₃ / Al₁₃Fe₄. Исследуются две упрощённые геометрии:

1. **Плоская граница** Al(111) / Fe₄Al₁₃(100) под контролируемой сжимающей нагрузкой.
2. **Эллипсоидное включение** Fe₄Al₁₃ в матрице Al под заданной деформацией включения (eigenstrain).

Магнитное поле напрямую не моделируется. Его действие заменено механическим суррогатом:
приинтерфейсной нагрузкой (плоская модель) и заданным eigenstrain включения (эллипсоид)
(source: `README.md`; `docs/article/eigenstrain_model.md`).

## Почему это физически важно

Fe-содержащие интерметаллиды — частые вторичные фазы в алюминиевых сплавах; они влияют на
локальную концентрацию напряжений, пластичность и развитие дефектов вокруг включений. Рабочая
гипотеза: деформация включения (в т.ч. магнитострикционная) создаёт локальное напряжение на
границе включение–матрица и зону повышенной деформации в Al (source: `README.md` §2, §5).

## Какой интерфейс выбран и почему

Al(111) / Fe₄Al₁₃(100) — лучший кандидат по mismatch-фильтру: максимальный mismatch длины
0.943 %, угловое рассогласование 0.114° (source: `docs/interface_mismatch_candidates.md`). Это
численный отбор ориентации, а не доказанное кристаллографическое OR.

## Какие результаты можно показывать

- Плоская модель прошла все нагрузки 0–200 MPa без численной катастрофы: нет ERROR/nan/потери
  атомов, Dangerous builds = 0, нет жёстких overlap < 1.8 Å, нет cross-slab Al-Fe контактов
  < 2.1 Å при 147/200 MPa (source: comparison CSV; `..._147mpa_check.md`; `..._200mpa_check.md`).
- Warning-пара 232-260 — **внутренняя** для Fe₄Al₁₃, контакт перемежающийся, без монотонного
  схлопывания, ни в одном кадре не ниже 1.8 Å (source: `docs/interface_trial_001_warning_pairs_check.md`).
- Эллипсоидный baseline стабилен: финальная T 300.36 K, Dangerous builds = 0, min pair 1.99 Å
  (source: `docs/ellipsoid_inclusion/ellipsoid_trial_001_nvt_300k_baseline.md`).
- Серия eigenstrain: все 4 случая прошли script-level sanity, без overlap < 1.8 Å; ε_z = 0.0100 —
  численная stress-test точка с бо́льшим force residual (source: eigenstrain series check + summary CSV).
- Главный результат — **воспроизводимый MD-пайплайн** обеих веток, а не финальный количественный
  прогноз напряжений.

## Какие ограничения нужно обязательно проговаривать

- Это **не финальная физическая валидация** (source: `docs/60_milestones/2026-05-14_article_ready_checkpoint.md`).
- Напряжение на атом — **comparative virial proxy**, а не абсолютное экспериментальное напряжение.
- Наибольший по модулю гидростатический proxy сидит у фиксированной нижней опоры (z = 5–10 Å,
  ≈ −4.18 ГПа) — это **likely boundary artifact**, а не максимум на интерфейсе (source: per-MPa check docs).
- 200 MPa — **controlled upper-bound / numerical failure-probe**, не подтверждённая прочность.
- Эллипсоидный eigenstrain — численный суррогат, **не** калиброванная магнитострикция.
- Геометрии упрощены; у эллипсоида искусственный зазор 2.2 Å; протоколы нагрузки неодинаковы
  (0 MPa = 5000, 60 = 10000, 120/147/200 = 15000 шагов); один trial на каждую ветку.
- OVITO-обзор проведён вручную, **скриншоты в репозитории не сохранены**.
