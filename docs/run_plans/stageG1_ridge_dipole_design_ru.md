# Stage G1: гребень Fe₄Al₁₃ + дислокационный диполь — дизайн и параметры запуска

Дата: 2026-08-13. Статус: инструментарий готов, геометрия сгенерирована и
проверена (DXA), smoke/production запущены раннером.

## Физическая постановка

Реализация идеи G1 из `stageG_extended_plasticity_evidence_ideas_ru.md`:

1. Однородный плоский eigenstrain-слой при p p f почти не передаёт напряжение в
   матрицу (факт Stage F: Δσ локализовано в первых ~4 Å). Напряжение в матрицу
   излучают **края** конечного включения. Минимальная геометрия с краем и
   трансляционной инвариантностью вдоль дислокационной линии — полуэллиптический
   **гребень** (цилиндр вдоль y) на поддерживающем слое Fe₄Al₁₃: 2D-сечение
   совпадает с эскизом Пшонкина «эллипс с отрезанной верхушкой».
2. Гомогенное зарождение дислокаций в идеальном Al требует ~ГПа; 147 МПа его не
   дадут никогда (отрицательный результат Stage F). Но напряжение Пайерлса в Al
   ~1–10 МПа, поэтому **готовая дислокация — чувствительный зонд**: поле краёв
   гребня заметно смещает её за пикосекунды–наносекунды.
3. «Поле двигает дислокации» — прямая MD-проверка механизма из статей группы
   (рост плотности дислокаций у интерфейса), без подмены его нереальным
   гомогенным зарождением.

## Протокол MD

| Параметр | Значение |
| --- | --- |
| Потенциал | MEAM Jelinek 2012 AlSiMgCuFe (как во всех стадиях A–F) |
| Timestep | 0.001 пс (1 фс) |
| Ансамбль | NVT 300 K (damp 0.1) на mobile; нижние 6 Å заморожены (setforce 0) |
| Соседи | `neigh_modify delay 0 every 10 check no` — обход бага KOKKOS `check_distance_kokkos` (milestone 2026-06-11); в smoke-минимизации `every 1 check no` |
| Smoke | minimize (cap 2000 итер.) + 3000 шагов NVT; гейты: завершение, нет ERROR/lost atoms/NaN, T=300±30, атомы constant |
| Production | **60 000 шагов** (60 пс) — нижняя граница по запросу; расширяемо рестартами |
| Dumps | каждые 1500 шагов (40 кадров/кейс, ~1.7 ГБ/кейс), поля: id type x y z pe + 6 компонент virial stress |
| Restart | каждые 10 000, ротация двух файлов |
| Seed | 88004 (конвенция проекта) |
| Backend | GPU: `lmp_kokkos_cuda.exe -k on g 1 -sf kk -pk kokkos newton on neigh half gpu/aware off` (RTX 3060 12 ГБ); автофоллбек: CPU `mpiexec -np 6` + OMP 2 — оба кейса всегда на одном backend |

Ключевая ставка GPU-lane: вся лестница GPU-восстановления Stage F падала с
`every 1 check yes` — т.е. на известном баге ядра `check_distance_kokkos`, а
рабочий обход `every 10 check no` (на нём прошли GPU-продакшены Stage A0/B/C/E и
единственный чистый GPU-smoke Stage F eps0000) в ней не перепроверялся. G1
использует обход; smoke — арбитр.

## Обязательный анализ (после production)

1. DXA по всем кадрам: x(t), z(t) каждой из 4 частичных; ширина расщепления;
   ширина диполя; ΔQ = Q_physical − Q_control.
2. Профиль σ(r) от плоского интерфейса вдали от гребня + карта σ_xz у края
   гребня (бины 2–5 Å, чувствительность к ширине бина).
3. CNA/PTM: лента дефекта упаковки между частичными, HCP-кластеры.
4. Временная устойчивость: тренды по ≥5 последовательным кадрам, не финальный кадр.
5. Критерии доказательности — из `stageG_extended_plasticity_evidence_ideas_ru.md`
   §3; смещения линий сверх 3σ шума control.

## Ожидания и честные исходы

- Смещаемость: v ≈ τb/B (B ~ 1–2·10⁻⁵ Па·с) → при Δτ ~ 10 МПа v ~ сотни м/с →
  равновесное смещение достигается за десятки пс; сенсорная чувствительность
  диполя ~ единицы Å при жёсткости ~8 МПа/Å.
- Если Δx(control↔physical) ≤ шума — это количественный отрицательный результат:
  «поле краёв при eps=0.00194 не смещает готовые дислокации на расстоянии
  ≥25 Å от края» — и мотивация для G2 (внешняя нагрузка + eps) или G3 (лестница eps).
