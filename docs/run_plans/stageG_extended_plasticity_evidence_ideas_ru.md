# Stage G (предложение): как доказать пластическую деформацию «нормальной длины»

Дата: 2026-08-13. Статус: идеи/план, расчёты не запускались.
Основание: Stage F CPU production (eps0000 vs eps00194), транскрипт встречи с Пшонкиным,
рукопись 0174 (06.06.25), JMMM 589 (2024) 171532, JAP 125 (2019) 023903, J. Alloys Compd 1020 (2025) 179430.

## 1. Почему нынешняя постановка не может дать «нормальную» пластичность

Факты из репозитория (docs/reports/stageF_cpu_results_key_*.md):

- Δσ_vm(control→physical) значим только в первых ~4 Å от интерфейса (пик 578 МПа в бине 0–2 Å),
  дальше — ниже шумового порога 133.5 МПа; DXA = 0, роста HCP нет. Вердикт: `absent/not_confirmed`.

Физическая причина — не ошибка расчёта, а порог зарождения:

- Гомогенное зарождение дислокации в бездефектном ГЦК Al требует RSS ~ μ/30 ≈ 0.9 ГПа
  (μ ≈ 26 ГПа), в MD-масштабах времени фактически 1.5–3 ГПа.
- Поле эйгендеформации даёт σ ~ 147 МПа (eps_z = 0.00194) — на порядок ниже порога зарождения.
  Максимальный фактор Шмида 0.5 → RSS ≈ 74 МПа. Дислокация из ничего при таких σ не родится
  ни за какое MD-время.
- Реальный сплав течёт при 120 МПа только потому, что в нём УЖЕ есть дислокации
  (ρ ~ 10¹²–10¹⁴ м⁻²), границы зёрен и источники. Экспериментальное утверждение группы —
  «поле повышает плотность дислокаций у интерфейса» — механистически означает
  **движение и размножение существующих дислокаций / эмиссию из готовых источников**,
  а не гомогенное зарождение.

Вывод: чтобы увидеть пластичность «нормальной длины», в модель нужно ввести
реалистичные источники дислокаций и/или воспроизвести реальную схему нагружения
(внешняя ползучесть 160 МПа + поле как возмущение).

## 2. Ранжированные идеи

### G1 (приоритет): готовая дислокация у интерфейса — «поле двигает дислокацию»

- Геометрия: F0-планарная ячейка (как сейчас), в Al на расстоянии r = 20–50 Å от интерфейса
  вставляется краевой дислокационный диполь или полупетля ½<110>{111} длиной 100–200 Å
  (готовые поля смещений: Atomsk / собственный генератор изотропной теории упругости).
- Пара control/physical идентичной геометрии; production ≥ 100 пс, NPT/NVT по текущему протоколу.
- Ключевая физика: напряжение Пайерлса в Al ~ 1–10 МПа. Поле в десятки–сотню МПа
  ГАРАНТИРОВАННО двигает готовую дислокацию — эффект измерим за наносекунды.
- Измеряемое: смещение линии (DXA-трекинг по кадрам), заметённая площадь → пластическая
  деформация, прогиб vs локальный RSS (сверка с линейным натяжением τ = μb/L),
  максимальная дистанция r*, на которой поле ещё двигает дислокацию → толщина
  «активного слоя» — прямой ответ физику вместо порога зарождения.
- Стоимость: та же F0-ячейка (~10⁵–10⁶ атомов), CPU-lane достаточно.

### G2: воспроизведение схемы эксперимента — внешняя нагрузка + поле как возмущение

- В экспериментах пластичность идёт при внешней ползучести σ = 160 МПа; поле лишь ускоряет её
  на ~25%. Поле ничего не обязано зарождать само.
- MD-аналог: одноосное растяжение ячейки до σ_ext чуть ниже порога текучести модели,
  затем control (eps=0) vs physical (eps=0.00194) при удержании σ_ext.
- Измеряемое: Δ(скорость накопления неаффинных смещений D²min), Δ(DXA-активность),
  Δ(релаксация напряжения). Это самый честный тест утверждения «поле смягчает матрицу».

### G3: лестница eps, легитимированная их же литературой

- В статьях группы два значения λ_m: 2.1e8 Н/(Т·м²) (JMMM 2024 → σ_m = 147 МПа)
  и 8e8 Н/(Т·м²) (JAP 2019 → σ_m ≈ 560 МПа при 0.7 Т). Разброс их собственных данных —
  фактор ~4, т.е. eps_z от 0.00194 до ~0.008 (E = 70–75.7 ГПа).
- Лестница eps_z ∈ {0.00194, 0.005, 0.008, 0.02, 0.05} — не «накрутка», а сканирование
  литературной неопределённости + поиск порога eps_crit зарождения на интерфейсе.
  Результат: «порог зарождения в идеальной ячейке = X; 147 МПа и 560 МПа лежат ниже/выше».
- Частично готово: структуры F0_planar_100A_eps005 и F1_curved_cap_100A_eps005 уже
  сгенерированы (structures/stageF_boundary_patch/).

### G4: реалистичный интерфейс — уступы, некогерентность, misfit-сетка

- Плоский соразмерный интерфейс искусственно подавляет зарождение: нет концентраторов.
  Реальный Fe₄Al₁₃/Al — некогерентный (моноклинный интерметаллид на ГЦК).
- Ввести атомные ступени (1–2 монослоя) на интерфейсе и/или использовать истинное
  несоответствие решёток → после релаксации возникает сетка misfit-дефектов;
  эйгендеформация двигает/выталкивает их в Al.
- Измеряемое: эмиссия с уступов (DXA у ступени), зависимость от eps.

### G5: граница зерна у интерфейса

- JAP 2019 прямо отмечает: наиболее активны включения на границах зёрен. ГЗ эмитируют
  частичные дислокации при 200–500 МПа — в разы ниже гомогенного порога.
- Бикристалл Al (высокоугловая ГЗ), пересекающий интерфейс; пара control/physical.

### G6: осциллирующая эйгендеформация (динамический суррогат)

- Эскизы Пшонкина: hν → колебания включения → упругие волны в матрицу. Статья
  J. Alloys Compd 2025 (та же связка LAMMPS+OVITO/DXA) показывает пороговую амплитуду
  колебаний, выше которой идёт размножение 1/6<112> Шокли.
- eps_z(t) = eps₀ + A·sin(2πft): искать пороговую амплитуду A_crit накачки дефектов.

### Вспомогательное: температура/время

- Зарождение термоактивировано; ns-масштаб MD компенсируется либо T-лестницей
  (300 → 500–600 K) с экстраполяцией Аррениуса, либо повышенным eps (G3). Использовать
  как модификатор G1–G5, не как самостоятельный вариант.

## 3. Критерии «доказанной пластичности нормальной длины» (фиксируются до запуска)

1. Суммарная длина DXA-линий ≥ 50–100 Å (≫ 8.47 Å), сохраняющаяся или растущая
   ≥ 50–100 пс на ≥ 5 последовательных кадрах.
2. Корректная кристаллография: полные ½<110> или пары частичных 1/6<112>, ограничивающие
   ленту дефекта упаковки (HCP-полоса в CNA/PTM между частичными).
3. Локализация D²min в планарной полосе вдоль {111} (полоса скольжения), а не изотропное облако.
4. Заметённая площадь / пластическая деформация выше порога, различие control/physical ≥ 3σ
   шума control.
5. Остаточность: после снятия eigenstrain (рампа вниз до 0) дефектная структура сохраняется —
   MD-аналог «магнитной памяти» (after-effect из JAP 2019/рукописи). Это сильнейший
   публикуемый сигнал.

Запрещённые формулировки остаются в силе: короткие сегменты 8–17 Å — только
«локальный DXA-сигнал / кандидат на зарождение».

## 4. Честный отрицательный исход тоже результат

Если даже с источниками (G1) поле при eps = 0.00194 даёт лишь упругое смещение линии на
единицы Å — это количественный ответ: «поле 147 МПа смещает готовые дислокации на X Å за Y нс;
гомогенное зарождение требует eps ≥ eps_crit». Для статьи это полноценный вывод, согласованный
с тем, что в эксперименте эффект виден только при внешней нагрузке (G2 — проверка).

## 5. Рекомендуемая последовательность

1. G1 (диполь у интерфейса, control/physical) — максимум информации на единицу затрат,
   вся инфраструктура F0 переиспользуется.
2. G2 (σ_ext + eps) — прямой мост к эксперименту группы.
3. G3-лестница — параллельно на свободных ресурсах (eps005-структуры уже готовы).
4. G4/G5/G6 — по итогам G1/G2.
