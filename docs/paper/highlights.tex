\section*{Highlights}
\begin{itemize}
\item An Al$_{13}$Fe$_4$ sphere inside an Al matrix is given a magnetostrictive strain.
\item At 0~K the response is elastic; a dislocation above it shifts 0.8~\AA{} and returns.
\item A compliant interface layer weakens the atomistic field by about 20\%.
\item Elastic estimate: stress above alloy yield stress in a shell about one radius thick.
\item At $V^*=70\,b^3$ the creep model needs 6--7 times the measured Fe--Al magnetostriction.
\end{itemize}
