# Numerical records

These machine-readable records support the manuscripts and figures. Distances
carry an `_A` suffix (angstrom), stresses `_MPa`, and times `_ps` where relevant.
JSON records define parameters and interpretation; CSV files hold profile or
frame data. The scripts in `analysis/python` document each calculation.

| Record prefix | Purpose and source |
|---|---|
| `calculation_validation` | Protocol checks, convergence evidence, corrected layer selection and remaining physical/provenance limitations |
| `stageG10_field_profile` | Paired static stress profile; full virials in `data/stageG4_clean`; regenerated with `stageG10_field_profile.py` |
| `stageG12_eigenstrain_retention` | Fe-sublattice deformation fit on the same static pair; `stageG12_eigenstrain_retention.py` |
| `stageG10_field_profile_free`, `stageG12_eigenstrain_retention_free*` | Diagnostic unconverged free relaxations discussed only as limitations in the supplement |
| `stageG2_depinning_*G15*` | Per-frame line coordinates and departure detector summaries; `stageG2_depinning.py`; deposited position trajectories |
| `stageG6_vstar_relA*` | Alloy staircase frame analysis and diagnostic activation-volume fit; complete trajectory in `data/publication/alloy` |
| `stageG8_eshelby3d` | Isotropic sphere and cylinder comparison, generated by `stageG8_eshelby3d.py` |
| `stageG6_stress_selection_relA` | Independent full-trajectory comparison of historical, Al-only and all-alloy stress masks |
| `stageG5_two_scale_bridge` | Conditional activated-glide integral and inverse stress estimates, generated by `stageG5_two_scale_bridge.py` |

The profile coordinate is `r = z - 20` angstrom. Nominal height above the
ridge crest is `d = r - 20`. Width averages and the central 20-angstrom window
are different spatial observables. Signed shear must not be replaced with a
positive invariant when interpreting a particular slip system.

The retained historical key `noise_floor_beyond_60A` denotes spatial statistics
of selected bins, not a measured numerical noise floor. Fit standard errors
in the retention calculation describe residuals within one configuration.
Neither quantity is an uncertainty across independent simulation runs.

The G15 detector groups segments by Burgers-vector family. When an original
line disappears, a later segment in that family may be unrelated. Candidate
events after a gap are therefore flagged separately from accepted departures.
Neither a missing line nor a short segment establishes a nucleation event.
