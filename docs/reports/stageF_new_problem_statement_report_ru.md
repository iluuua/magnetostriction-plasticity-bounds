## 1. Краткий вывод

В новой постановке моделируется не весь микронный объём, а локальный участок плоской границы Fe₄Al₁₃/Al с матрицей Al, и сравниваются два расчётных случая при одинаковом протоколе: baseline `eps0000` и physical case `eps00194`. Механический эффект магнитострикции задан не через явное магнитное поле, а через eigenstrain `eps ≈ 0.00194`. Обе CPU-производственные траектории по 50 000 шагов завершились чисто (returncode 0), при идентичных `Lx/Ly`, `zhi = 200 Å`, граничных условиях `p p f` и одинаковом бинаре/протоколе; CPU- и GPU-результаты не смешивались. По разности `Δ = eps00194 − eps0000` подтверждена локальная передача напряжения в матрицу Al: пик добавочного von Mises proxy напряжения `+578.422 MPa` в первом слое у границы (`r ≈ 1 Å`). Значимый выше шума слой `Δσ_vm` составляет всего `≈ 4 Å`, дальше сигнал быстро падает к шумовому уровню (`133.527 MPa`). Развитые дислокации не обнаружены (`DXA line length = 0 Å` в обеих cases), остаточная пластичность не подтверждена (`not_confirmed`). Текущее состояние интерпретируется как преимущественно упругое напряжённое состояние с локальным интерфейсным structural-откликом. Новые MD-расчёты по итогам этого отчёта автоматически не запускаются.

## 2. Новая постановка задачи

**Почему локальный участок, а не весь объём.** Прямой атомистический расчёт полного микронного включения и полного образца недоступен по числу атомов и времени. Поэтому моделируется локальный участок плоской границы Fe₄Al₁₃/Al с прилегающей матрицей Al масштаба ~100 Å по нормали к границе. Задача этой модели — ответить на локальный вопрос: как поле напряжений в Al matrix изменяется при заданной деформации на границе, и есть ли структурные признаки пластичности рядом с границей.

**Что такое F0 planar boundary patch.** F0 — это плоская локальная граница (planar interface XY) между стороной Fe₄Al₁₃ и матрицей Al. Это упрощённая геометрия: плоская граница без кривизны, локальный слэб, а не искривлённый колпак включения и не весь микронный образец.

**Baseline — `eps0000`.** Расчётный случай без добавочной деформации включения/границы. Он нужен как собственный интерфейсный фон: у любой границы Fe₄Al₁₃/Al уже есть напряжения из-за рассогласования решёток и свободной поверхности сверху. Baseline позволяет отделить этот фон от добавочного эффекта.

**Physical case — `eps00194`.** Тот же участок границы, но с заданной деформацией `eps ≈ 0.00194` по нормали Z (eigenstrain). Это механический эквивалент магнитострикционного воздействия.

**Что означает eigenstrain.** Это заданная (собственная) деформация включения/границы по оси Z, которую вкладывают в расчёт как начальное несоответствие, а не как внешнюю силу или поле. В этой постановке магнитострикционное воздействие не моделируется как явное магнитное поле. Вместо этого его механический эффект задаётся через eigenstrain `eps ≈ 0.00194` в расчётном случае `eps00194`. Baseline `eps0000` нужен, чтобы отделить собственный интерфейсный фон от добавочного эффекта eigenstrain.

**Почему сравнение через Δ.** Абсолютные атомные virial-значения содержат интерфейсный фон и локальный шум. Чистый ответ даёт разность `ΔQ(r) = Q_eps00194(r) − Q_eps0000(r)` при одинаковом протоколе: она вычитает общий фон и оставляет именно добавочный эффект eigenstrain.

**Что считается наблюдаемым результатом:**
- напряжённый слой у границы и его форма по `r`;
- локализация (насколько далеко в матрицу проникает добавочный сигнал);
- структурные индикаторы пластичности (HCP/OTHER, DXA).

**Что НЕ является целью текущей модели:**
- это не полное включение масштаба 5 μm;
- это не полный образец масштаба 20 μm;
- это не прямое моделирование магнитного поля;
- это не континуальный FEM-расчёт.

## 3. Геометрия и расчётная схема

**Система.** Матрица Al; сторона/интерфейс Fe₄Al₁₃; плоская граница между ними.

**Координаты.** Плоскость границы = XY. `r = 0` на границе (`z_interface ≈ 50 Å`), `r = +Z` — вглубь матрицы Al. Все профили строятся по `r` (бины по расстоянию от границы).

**Граничные условия.** `p p f` — периодические по X и Y, непериодическая по Z. `zhi = 200 Å` — это nonperiodic headroom (свободное пространство над слэбом по Z), а не жёсткая стенка (`wall = false`) и не box/relax (`box_relax = false`).

**Cases.** `eps0000` (baseline) и `eps00194` (physical). Обе идут по идентичному протоколу.

**Почему нужен одинаковый протокол.** Δ-сравнение валидно только если различается ровно один фактор — eigenstrain. Поэтому у обеих cases одинаковые `Lx/Ly`, одинаковый `zhi`, один и тот же CPU-бинарь/протокол и одинаковая длина production 50 000 шагов.

**Почему CPU-результат валиден.** Обе production завершились чисто (`returncode 0`, `completed_clean`, `max_step = 50000`). Результаты CPU и GPU не смешивались: физический вывод строится только на CPU comparable pair.

## 4. Использованные формулы

**1. Связь магнитострикция → eigenstrain (исходная оценка).**

Оценка магнитострикционного напряжения:

```
σ_m = λ_m · B
```

где `B = 0.7 T`, `λ_m = 2.1 × 10⁸ N/(T·m²)`, откуда `σ_m ≈ 147 MPa`.

Перевод в деформацию:

```
ε ≈ σ / E
```

где `E_Al ≈ 75.7 GPa`, откуда `ε ≈ 147 MPa / 75.7 GPa ≈ 0.00194`.

В расчёте используется `eps00194` как механический эквивалент магнитострикционного воздействия.

**2. Baseline subtraction.**

```
ΔQ(r) = Q_eps00194(r) − Q_eps0000(r)
```

где `Q` может быть `σ_vm`, `σzz`, above-yield fraction, доля HCP/OTHER.

**3. Координата.**

```
r = z − z_interface,   z_interface ≈ 50 Å
```

`r > 0` — область матрицы Al.

**4. Von Mises напряжение.**

```
σ_vm = sqrt( 0.5 · [ (σxx − σyy)² + (σyy − σzz)² + (σzz − σxx)² + 6·(σxy² + σyz² + σxz²) ] )
```

Важно: в расчёте используется local virial stress proxy (LAMMPS `stress/atom`), приведённый как

```
σ_mpa = −Σ(c_st) / (Lx · Ly · bin_width) · 0.1
```

Этот proxy не равен идеально калиброванному continuum-напряжению. Он нужен для сравнения `eps00194` vs `eps0000` при одинаковом протоколе, поэтому надёжнее читать форму профиля и baseline-Δ, чем абсолютные atom-level p95-значения.

**5. Порог/ориентир текучести.**

```
σ_y,Al ≈ 120 MPa
```

Используется не как доказательство пластики, а как ориентир зоны повышенных напряжений.

**6. Above-yield fraction.**

```
f_yield(r) = N(σ_vm > 120 MPa) / N_total(r)
```

**7. Толщина слоя.**

```
h = сумма ширин смежных (contiguous) бинов, где выполняется критерий
```

Критерии: `total σ_vm > 120 MPa` (даёт «толщину» по proxy) и `meaningful Δσ_vm above noise` (даёт добавочный слой выше шума).

**8. Доли дефектов.**

```
f_HCP(r)  = N_HCP(r)  / N_Al(r)
f_OTHER(r) = N_OTHER(r) / N_Al(r)
Δf_HCP(r)  = f_HCP,eps00194(r)  − f_HCP,eps0000(r)
Δf_OTHER(r) = f_OTHER,eps00194(r) − f_OTHER,eps0000(r)
```

**9. Длина дислокационных линий (DXA).**

```
L_DXA = суммарная обнаруженная длина дислокационных линий
```

В финальной проверке `L_DXA = 0 Å` для обеих cases — развитые дислокационные линии не обнаружены.

**10. Критерий остаточной пластичности.**

Пластическая деформация в этом отчёте считается подтверждённой только при устойчивых структурных индикаторах: persistent HCP/OTHER-кластеры выше baseline; ненулевой/устойчивый DXA; остаточный дефектный паттерн в финальном кадре — а не просто высокое напряжение. Явно: **высокий `σ_vm` сам по себе не является доказательством пластической деформации.**

## 5. Как обрабатывались данные

- **Production pair.** Берётся пара завершённых CPU-траекторий (`eps0000`, `eps00194`), обе по 50 000 шагов, dump каждые 1000 шагов (51 кадр).
- **Окно усреднения.** Основное окно — `last20_mean` (последние 20% траектории), чтобы усреднить тепловой шум; дополнительно используются кадры `initial` и `final`.
- **Бины по `r`.** Матрица Al (`type = 1`, `z ≥ 50 Å`) разбивается на бины по расстоянию `r` от границы; в каждом бине считаются средние компоненты напряжения и доли дефектов.
- **Δ.** Для каждого бина вычисляется `ΔQ(r) = Q_eps00194(r) − Q_eps0000(r)`.
- **Stress proxy.** Напряжение — local virial (`stress/atom`), приведённое формулой из раздела 4; читается как относительная метрика для Δ-сравнения.
- **Defect metrics.** CNA/DXA выполнены в OVITO 3.15.4 для кадров `step 0` и `step 50000`; поле `Dmin2`/atomic-strain не сохранено в dump и отдельно не заявляется.
- **Noise floor.** Робастный far-field шум `Δσ_vm` оценён по `r_center ≥ 70 Å` как `median(|Δ|) + 2·1.4826·MAD = 133.527 MPa`; относительно него определяется «meaningful» слой.

## 6. Результаты по напряжениям

**1. Пик добавочного von Mises proxy.**
`Peak Δσ_vm = +578.422 MPa` в первом слое у границы: `r ≈ 1 Å`, bin `0–2 Å`, окно `last20_mean`. Абсолютные уровни в том же бине: `σ_vm(eps00194) = 2860.344 MPa`, `σ_vm(eps0000) = 2281.921 MPa`.

**2. Значимый слой Δσ_vm выше шума.**
Meaningful `Δσ_vm above noise ≈ 4 Å`; первый бин ниже шума — `4–6 Å` (`Δ = 1.673 MPa` при noise floor `133.527 MPa`). То есть добавочный сигнал уверенно виден только в первых ~4 Å.

**3. Слой `total σ_vm > 120 MPa`.**
`121.068 Å` — до края доступного Al slab (одинаково для mean и p95). Это НЕ толщина пластической зоны: `total σ_vm` включает интерфейсный фон и остаётся выше `120 MPa` по всему доступному слэбу, поэтому «120 MPa» здесь — не чистый физический cutoff, а порог local virial proxy, упирающийся в край расчётной области.

**4. Δσ_vm на расстояниях (checkpoints).**

| r | Δσ_vm mean | комментарий |
| ---: | ---: | --- |
| 0–5 Å | +161.264 MPa | сильный near-interface Δ |
| 10 Å | −1.149 MPa | около нуля |
| 20 Å | −12.454 MPa | ниже шума |
| 50 Å | −20.441 MPa | ниже шума |
| 100 Å | +30.160 MPa | мал относительно interface peak |

**5. Δσzz на расстояниях.**

| r | Δσzz mean |
| ---: | ---: |
| 0–5 Å | −42.178 MPa |
| 10 Å | +8.274 MPa |
| 20 Å | +6.966 MPa |
| 50 Å | −69.071 MPa |
| 100 Å | +24.070 MPa |

**6. Directional dominance.**
В пике VM (`r ≈ 1 Å`) компоненты: `Δσxx = −160.130`, `Δσyy = −607.587`, `Δσzz = +52.308 MPa`. Доминирует `Δσyy`, а не `σzz`. Поэтому `σzz dominance = not_confirmed`: пик определяется смешанным интерфейсным von Mises и компонентой `Δσyy`, а не прямой Z-компонентой eigenstrain.

**Ответы простым языком:**
- Есть ли передача напряжения? — Да, confirmed (`Δσ_vm` пик `+578.422 MPa`).
- Где максимум? — В первом слое у границы (`r ≈ 1 Å`).
- Насколько далеко идёт эффект? — Meaningful Δ ≈ 4 Å, дальше быстро падает к шуму.
- Можно ли говорить про слой 121 Å? — Нет, не как про plastic layer; это total virial proxy до края слэба.

## 7. Результаты по пластическим деформациям и дефектам

**1. DXA.**
Финальная длина дислокационных линий: `eps0000 = 0 Å`, `eps00194 = 0 Å` (`step 50000`, OVITO 3.15.4). Развитые дислокации не обнаружены.

**2. HCP.**
Практически отсутствует: `eps0000 max = 0.000862` (1 атом в бине `r ≈ 1 Å`), `eps00194 max = 0.0`. `Δf_HCP` по модулю ≤ `0.000862`.

**3. OTHER / non-FCC.**
Максимальный финальный `|ΔOTHER/non-FCC| = 0.035964` около `r ≈ 3 Å` (bin `2–4 Å`). Это слабый локальный интерфейсный structural-отклик (перестройка топологии у границы/свободной поверхности), а не доказательство пластичности. Для контекста: сама доля OTHER у границы велика в обеих cases (`eps0000 ≈ 0.936`, `eps00194 ≈ 0.966` при `r ≈ 1 Å`) — это структура самой границы, а не добавочный дефект.

**4. Остаточная пластичность.**
Вердикт: `not_confirmed`. Нет устойчивой дислокационной сети, нет `Dmin2`-доказательства, финальные CNA/DXA не устанавливают persistent plasticity.

**5. Итог по этому разделу.**
- stress transfer — confirmed;
- plastic deformation — not confirmed;
- текущее поведение — преимущественно упругий / локальный интерфейсный structural отклик.

Раздел явно разделяет три вещи: **напряжённое состояние** (есть, у границы), **пластическая перестройка** (не подтверждена), **дислокации** (не обнаружены).

## 8. Интерпретация

Физически результат означает следующее. Заданная деформация на границе (`eps00194`) создаёт добавочное поле напряжений, локализованное в очень тонком слое матрицы Al у границы: максимум добавочного von Mises proxy `+578.422 MPa` при `r ≈ 1 Å`, значимый выше шума слой `≈ 4 Å`. Уже на `10–20 Å` добавочный сигнал падает до уровня теплового/атомного шума; значения на `50` и `100 Å` (`−20.441` и `+30.160 MPa`) малы по сравнению с interface peak и с noise floor `133.527 MPa`. Это картина упругой передачи напряжения с сильной локализацией у границы.

Пик определяется смешанным интерфейсным von Mises и компонентой `Δσyy`, а не прямой Z-компонентой eigenstrain, поэтому нельзя говорить о «чистом σzz-эффекте по оси эйгенстрейна». Структурные индикаторы (HCP практически ноль, `ΔOTHER ≤ 0.036`, `DXA = 0`) не показывают устойчивой пластической перестройки. Следовательно, на масштабе и времени этой локальной модели eigenstrain `eps ≈ 0.00194` даёт упругий отклик, а не развитую пластичность.

## 9. Ограничения

1. **Local virial stress proxy.** Атомный virial (`stress/atom`) не равен напрямую continuum-напряжению; абсолютные MPa (особенно p95 atom-level) не калиброваны. Сравнение валиднее через Δ при одинаковом протоколе.
2. **F0 planar.** Это плоская локальная граница, а не искривлённое включение и не весь micron-scale образец. Влияние кривизны в этой модели не проверяется.
3. **CPU-результат.** GPU production не получена из-за backend blocker; физические выводы основаны на CPU comparable pair. GPU в физический результат не входит.
4. **Пластичность.** Нет теста разгрузки/восстановления (unload/recovery), поэтому остаточную пластичность доказать нельзя; текущая проверка опирается на финальную структуру / DXA / HCP / OTHER.
5. **Время / размер.** 50 000 шагов и локальный слэб масштаба ~100 Å по нормали; по этим данным нельзя делать выводы о полном включении масштаба 5 μm.
6. **Порог 120 MPa.** Используется как ориентир, а не как автоматическое доказательство текучести в атомной local stress метрике.

6. Остаточная пластичность не подтверждена (`not_confirmed`).
